# 🚀 Benchmark: C vs C++

## 📊 Results

### 🔢 Sorting 1 Million Integers

| Language | Time |
|----------|------|
| C++ | 68074µs |
| C | 117562µs |

✅ **C++ was faster by 49488µs**

---

### ⚡ Accessing 50 Million Integers

| Language | Time |
|---|---|
| C++ | 38277µs |
| C | 46380µs |

✅ **C++ was faster by 8103µs**

---

### 🧠 Allocating and Filling 1 Million 1KB Memory Blocks

| Language | Time |
|----------|------|
| C++ | 435341µs |
| C | 108219µs |

✅ **C was faster by 327122µs**

---

### 🔤 String Manipulation (Concatenation + Uppercase)

| Language | Time |
|----------|------|
| C++ | 61µs |
| C | 59µs |

✅ **C was faster by 2µs**

---

# 📌 Conclusion

- **C++ showed significant advantages in:**
  - Sorting
  - Accessing large volumes of data

- **C performed better in:**
  - Massive memory allocation
  - Simple string manipulation

> Benchmark executed with randomly generated data in a local environment.
